# 透析 内服薬レビュー（個人の診療参考用）

血液透析患者の検査値と処方から、内服薬の追加・中止・用量調整の検討候補を提示する Web アプリ（PWA）です。

- 個人の診療参考用に作成したもので、**医療機器ではありません**。提示内容は検討候補であり、最終判断は医師が添付文書・ガイドラインを確認して行ってください。
- 入力した検査値・処方は端末内のみで処理され、外部に送信・保存されません。
- iPhone では Safari で開き、共有ボタン →「ホーム画面に追加」でアプリとして使えます。初回表示後はオフラインでも動作します。

## 主な根拠
- 日本透析医学会「慢性腎臓病に伴う骨・ミネラル代謝異常の診療ガイドライン（2025年改訂版）」
- 日本透析医学会「慢性腎臓病患者における腎性貧血治療のガイドライン」2025年版
- 日本透析医学会「透析患者の糖尿病治療ガイド2025」
- 日本腎臓病薬物療法学会「腎機能低下時に最も注意の必要な薬剤投与量一覧」2025年改訂38版

## 更新時の注意
`index.html` を更新したら、`sw.js` の `VERSION` を変更してください（スマホに残った古いキャッシュが入れ替わります）。
